# Capricorn

A local-first terminal coding agent that runs Gemma 4 models through a local
[Ollama](https://ollama.com) daemon.

Capricorn is a fork of Google's open-source
[Gemini CLI](https://github.com/google-gemini/gemini-cli) (Apache-2.0). It is an
independent project, not affiliated with Google.

**Work in progress.** Documentation will be published with the first release.
